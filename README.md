# Food Landing Page

A responsive food landing page built with HTML and CSS, recreated from a Figma design.

## 🔗 Live Demo
https://food-landing-page-tejiri.netlify.app/

## 🎨 Design
This project was built by replicating a Figma design and translating it into a functional, responsive web page.


Figma design: https://www.figma.com/design/zos84TfJducjywEq48AJ1r/frontend-design-task?node-id=2337-5&t=X66fMn1JHfrKUYSk-1

## 🛠️ Built With
- HTML5
- CSS3

## 📱 Features
- Responsive layout
- Clean and modern UI
- Semantic HTML structure

## 🎯 Purpose
This project was created to practice frontend development skills, specifically converting a Figma design into a fully responsive webpage using only HTML and CSS.

## 🚀 Getting Started
To view the project locally:
1. Clone the repository
2. Open `index.html` in your browser
